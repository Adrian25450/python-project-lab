# Python Project Lab 🐍

Seis proyectos prácticos de Python para automatización, análisis, datos y desarrollo de aplicaciones. Cada carpeta es independiente y contiene instrucciones propias.

## Proyectos

| Proyecto | Qué demuestra |
|---|---|
| 🧮 SmartCalc | Calculadora de consola con operaciones, expresiones y memoria de historial. |
| 📊 SalesLens | Análisis de ventas desde CSV con indicadores y gráficas exportables. |
| 💸 Finanzas personales | Registro de ingresos/gastos con SQLite, categorías y exportación CSV. |
| 🗂️ FileFlow | Clasificación segura de archivos con vista previa y reporte. |
| 📦 Inventario API | API REST con Flask y SQLite para productos, stock y movimientos. |
| 🌦️ Clima interactivo | Panel Streamlit con pronóstico y visualizaciones de Open-Meteo. |

## Requisitos

Python 3.10 o superior. Para ejecutar cada proyecto, instala únicamente sus dependencias desde su carpeta:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Revisa el README dentro de cada carpeta para ejemplos, formatos de datos y comandos. Los proyectos que consumen APIs requieren internet. Los datos suministrados son ficticios.

## Enfoque técnico

El conjunto cubre manejo seguro de expresiones, lectura y transformación de CSV, gráficos con Matplotlib, persistencia SQLite, diseño de endpoints REST, validación de entradas, automatización no destructiva y consumo de API pública.
