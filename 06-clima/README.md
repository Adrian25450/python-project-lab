# Clima interactivo 🌦️

Panel web en Streamlit que consulta Open-Meteo, busca ciudades y muestra temperatura actual y pronóstico diario en gráficos.

## Ejecución

```bash
pip install -r requirements.txt
streamlit run app.py
```

Escribe una ciudad (p. ej. Cartago, Colombia). Requiere conexión a internet; la API pública no necesita clave. Se presentan 7 días de pronóstico cuando hay disponibilidad.
